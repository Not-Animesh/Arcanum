# Code of Conduct

## Our Pledge

We, the contributors to the Adaptive Learning Platform, pledge to make participation in this project a harassment-free experience for everyone, regardless of experience level, background, or role on the team. This applies equally to all three team members and to anyone outside the team who opens an issue or pull request.

## Our Standards

Examples of behavior that contributes to a positive environment:

- Giving constructive, specific feedback on code and design decisions rather than vague criticism
- Being patient when reviewing work from teammates who are still learning (this project explicitly has one beginner-level contributor — impatience with their pace or questions is not acceptable)
- Assuming good intent when a pull request has issues, and explaining *why* something needs to change
- Crediting teammates for their work in commit messages, PR descriptions, and the final project report

Examples of unacceptable behavior:

- Personal attacks, mocking, or dismissive comments about a teammate's skill level
- Rewriting a teammate's code without discussion instead of reviewing it through a pull request
- Taking credit for work you did not do, especially in the context of academic submission
- Publicly disparaging a teammate's contribution in front of the guide or evaluators

## Scope

This applies within all project spaces — the GitHub repository (issues, PRs, discussions), any shared chat used for coordination, and in-person meetings related to this project.

## Enforcement

Since this is a 3-person academic team, disagreements should first be raised directly between the people involved. If that doesn't resolve it, escalate to the full team in a short sync before involving the project guide. Repeated or serious violations (harassment, plagiarizing a teammate's work, deliberately sabotaging shared branches) should be raised with the guide named in the [Project Approval Form](README.md).
